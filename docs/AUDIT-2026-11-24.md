## Done on 2026-11-25 (developer decisions)
- Loan policy: 7 days, up to 8 books per member (`backend/src/config/loanPolicy.ts`; tests use the constant).
- Email code at sign-in stays as the second factor (2FA); no school confirmation needed.
- Release signing: Android release keystore in `~/aklatone-keys/` (outside the project), Gradle signs release
  APK/AAB from it or from CI secrets; verified with apksigner. Windows signing in the Release workflow when a
  certificate secret exists.
- Server: HTTPS proxy (Caddy) in `docker-compose.yml` + `Caddyfile`, `TRUST_PROXY: 2`; off-site backup script
  `scripts/offsite-backup.sh`; uptime check documented (docs/DEPLOYMENT.md).
- CI: `.github/workflows/release.yml` (tag v* -> signed Android, Windows/Linux installers, GitHub Release);
  both workflows pass actionlint.
